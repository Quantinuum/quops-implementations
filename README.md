# quops-implementations
Implementations of QUOPS in Guppy and pytket.

## Using `uv`

This repository uses `uv` for Python environment and dependency management.

## Setting up the virtual environments

The Guppy and pytket notebooks require different virtual environments. These two environments can be set up by running `make setup` in the project root, which will also create two Jupyter kernels called QUOPS Guppy and QUOPS Pytket.
